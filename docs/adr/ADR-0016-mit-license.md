# ADR-0016: MIT license

**Status:** Accepted · **Date:** 2026-10-03

## Context

No license was supplied; the owner publishes open educational content under hybridcloudworks.com.

## Decision

MIT with a NOTICE file acknowledging Microsoft documentation as the rule source. **Owner may change this before publication**.

## Consequences

Permissive reuse; change requires updating LICENSE, NOTICE and package.json.
